# Sinhala Transliteration Accuracy Testing - Assignment 1

## Objective

This project evaluates the accuracy of the Chat Sinhala transliteration function on https://www.pixelssuite.com/chat-translator. It identifies negative test scenarios where chat-style Singlish input is not correctly converted into Sinhala output.
